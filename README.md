# lucky的鱼塘 · fishpond

> 一座只求慢的网页钓鱼池塘。不必争抢，鱼来了，便接住。

纯静态、零依赖的休闲钓鱼小游戏：WebGL 水面 + 九种塘鱼 + 全手势垂钓。
双击 `index.html` 即可游玩，无需构建、无需框架、无任何外部依赖。

**在线试玩**：https://rulke.github.io/fishpond/

## 玩法

| 手势 | 动作 |
|---|---|
| 按住湖面拖动 | 扇面瞄准：方向 + 远近，松手抛竿 |
| 浮漂没顶 | 快速上滑或点水——起竿！ |
| 起竿后按住不放 | 收线遛鱼：指针出青瓷弧或线转粉就松一松 |
| 等待时长按水面 | 收线换钓点（脱钩后漂会留在原地） |
| 鱼绕饵打转 | 是试探——别动它 |

- 九种鱼各有脾气：**饵对了才肯来**，稀客要看花运与静心
- 荷花近旁花运更好；放流积静心，收进篓篓记斤两
- 鱼鉴按稀有度分五组：寻常 / 雅致 / 珍奇 / 月华 / 传说

## 亮点

- **真鱼咬钩**：塘里的鱼就是能钓的鱼——鱼影渐近、绕饵试探、叼饵黑漂拖走浮漂
- **竿随线转**：竿身绕握点追踪漂与鱼的方位，弯曲随张力；线即张力计（白→粉预警）
- **全手势操作**：无动作按钮，起竿、遛鱼、收线都是水上的物理动作
- **青瓷水彩视觉**：WebGL 折射水面、锦鲤群、荷塘四季，无贴图纯程序绘制

## 技术

- 原生 JavaScript（ES2017，IIFE 模块，无构建步骤）
- WebGL 片元着色器实时水面模拟与折射渲染（`js/water.js`）
- SVG 程序化绘制：竿、漂、九种鱼插画、鱼鉴
- 存档仅用 `localStorage`（键前缀 `fishpond_`），无网络请求、无追踪

## 目录结构

```
index.html        唯一入口（骨架与脚本挂载）
styles.css        全站样式
js/bg-data.js     水面底图 data URL（file:// 下 WebGL 需要）
js/water.js       WebGL 水面模拟与折射渲染
js/life.js        荷花 / 浮叶 / 花瓣 / 九种塘鱼
js/fishing.js     钓鱼状态机、鱼种表、张力系统
js/tackle.js      竿 / 线 / 漂绘制与抛竿、收线、起竿动画
js/app.js         手势路由、渔获卡、鱼鉴、存档
flash1.png        水面折射底图（原图）
fish.png          渔获卡水彩底图
```

## 本地运行

方式一：直接双击 `index.html`（file:// 可完整游玩）。

方式二（推荐）：

```bash
python -m http.server 8642
# 打开 http://127.0.0.1:8642
```
